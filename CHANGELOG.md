# Change Log

All notable changes to the "Smart Phrases" extension will be documented in this file.

## [0.0.1] - 2024-01-31

### Initial Release

- Trigger word expansion functionality
- Support for space, tab, and enter triggers
- Phrase management UI with add, edit, and delete capabilities
- JSON file editing support
- Auto-completion suggestions while typing
- Clean and intuitive user interface
- Persistent storage of phrases
